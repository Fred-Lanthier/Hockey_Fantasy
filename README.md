# Hockey_Fantasy
The objective of this repo is to Scrap the internet to get NHL players' salaries not available on the fantasy website in case you don't want to pay for it. The app my friends and I are using is called Fantrax and we need to pay to get the salary cap option, so I created this repo to help others to get access to full Fantrax version without paying.

1. (Optional) Create a CONDA environment

2. Clone the repository locally and install the depedences

To use the internet scrapper, copy past these lines in your terminal :
git clone https://github.com/Fred-Lanthier/Hockey_Fantasy.git
cd Hockey_Fantasy
pip3 install -r requirements.txt

3. How to use the repo
To use the repo, you will first need to download a .csv file of your league info. This repo is made for the Fantrax app. To get the .csv file, go to your league, then select Players. In the Status/Team onlget, select "All"
and click on the downlaod all as csv button.
